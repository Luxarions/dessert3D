Engine Documentation & Module FAQ

LXRN Math supports full 2D, 3D, and 4D vector algebra with Vec2, Vec3, and Vec4, as well as matrix transformations with Mat2, Mat3, and Mat4. All structures use column-major typed Float32Arrays for maximum WebGL/WebGPU performance.


Key Operations:

  • Vec3.dot(a, b) - Computes vector dot product
  • Vec3.cross(a, b) - Computes 3D cross product
  • Mat4.perspective(fov, aspect, near, far) - Creates perspective projection matrix
  • Mat4.lookAt(eye, target, up) - Computes camera view matrix
  • Mat4.invert() - Fast 4x4 matrix inversion
  • Mat4.getPosition(target) - Extracts translation component

Memory is optimized with contiguous array buffers to prevent garbage collection overhead during high-frequency frame renders.

The Quat, Euler, and DualQuat modules provide smooth rigid body transformations, gimbal-lock-free spherical interpolation (Slerp), and dual quaternion skinning algorithms.


Rotation Features:

  • Dual Quaternion kinematics for skinning without volume loss ("candy-wrapper" artifact fix).
  • Full Euler angle order support: 'XYZ', 'YXZ', 'ZXY', 'ZYX', 'YZX', 'XZY'.
  • Spherical Linear Interpolation (Quat.slerp) with shortest-path checking.
  • setFromRotationTranslation(rotation, translation) for unified rigid body transform initialization.

The engine is integrated with AutoUpdate.js to automatically monitor file changes across /src, /test, and subdirectories.


Watcher Capabilities:

  • Chokidar File Monitor: Tracks file additions, modifications, and deletions in real-time.
  • Automatic Server Reload: Gracefully restarts the dev process upon new module creation.
  • Dynamic Test Suite Registration: Automatically discovers newly created *.test.js files via Vite glob imports.
